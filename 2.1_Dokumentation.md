#Aufgabe 2.1#

Ziel: Prediction  von Einwürfen
Modell entwickeln, was die Wahrscheinlichkeit von Einwürfen und die Partei des Kommentators vorhersagen kann.

Vorgehensweise:

##1. Datenvorbereitung (bereits geschehen)##

##2. Explorative Datenanalyse##
- Häufigkeitsanalyse
    => Was? Häufigkeit von Wörtern und Phrasen zählen, die vor einem Einwurf stehen
    => Wie? - Segmente verwenden, in denen "interruption" = true ist
            - nltk-Bibltiothek, um häufige n-Gramme zu extrahieren

- Word Clouds
    => visuelle Darstellung der Wörter, die häufig vor einem Einfwurf Kommentator

- Kontextanalyse
    => Kontext , in dem Einwürfe auftreten, analysieren. Bspw.: Ob Themen oder Reden bestimmter Politiker häufiger unterbrochen werden  

- Parteizugehörigkeit der Kommentatoren der Einwürfe bestimmen
    => Datenaggregation: Anzahl der Einwürfe pro Partei zählen
    => Visualisierung: Balkendiagramm, um die Verteilung der Einwürfe nach Partei darzustellen

Bonus: Zeitreihenanalyse
        => analysieren, ob sich die Häufigkeit und die Partei der Einwürfe über die Jahre verändert haben.

##3. Feature Engineering##
- Textfeatures
    => Tokenzier und Embeddings aus Huggung Face Transformers (z.B. BERT -> Pre Traines Transformer Modell) verwenden

- Kontextuelle Features
    => n-Gramme, POS-Tags und andere linguistische Merkmale extrahieren

##4. Modellierung##
- Vorhersage der Unterbrechungszeitpunkte
    => BERT oder RoBERTa finetunen, um die Wahrscheinlichkeit eines Einwurfs für jedes Segment vorherzusagen
- Vorhersage der Partei des Kommentators
    => Multiklassen-Klassifikationsmodell verwenden, um die Partei des Kommentators basierend auf dem Segment zu bestimmen, bei dem ein Einwurf vorhergesagt wurde.

##5. Training und Validierung##
- Training
    => Modell mit einem Teil der Daten trainieren und mit einem anderen Teil validieren
- Hyperparameter-Optimierung
    => Beste Hyperparameter finden, indem man Grid Search oder Bayesian Optimization verwendet

##6. Evaluierung##
-Performance Metriken
    => Leistung der Modelle bewerten, indem wir Precision, Recall, F1-Score und ROC-AUC verwenden

##7. Implementierung und Anwendung##
- Deployment
    => Modell mithilfe von Hugging Face APIs deployen
